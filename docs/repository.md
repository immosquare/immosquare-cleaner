# Cleaning a whole repository with immosquare-cleaner

Given a directory instead of a file, immosquare-cleaner cleans every source file of a repository in one parallel run, whatever its stack: a TypeScript package, a Rust or Tauri app, a Go module, a Rails app, or a folder holding several of them. This page explains how the files are selected, what is excluded, and how to tune the run.

## When to clean a whole repository

A repository clean is the command to run when adopting immosquare-cleaner on an existing codebase, after upgrading it, or after a large refactor. Day to day, the agent hook and the editor on-save integration format files one at a time as they are edited. Run it from the repository root:

```bash
immosquare-cleaner .
```

Commit or stash your work first: the run rewrites every file it formats, and a clean working tree makes the resulting diff easy to review.

## How a repository clean selects its files

Files are selected in four steps, each narrowing the list of the previous one:

| Step              | Behaviour                                                                                                                                                                                                                                                                                                                                                    |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Listing           | Files come from `git ls-files` (tracked and untracked, minus `.gitignore`), so build output is skipped by the repository's own rules. A nested repository or a submodule is walked with its own listing, so a folder holding several repositories cleans all of them. Outside git, every file under the directory is listed.                                 |
| Excluded folders  | `.git`, `build`, `coverage`, `dist`, `log`, `node_modules`, `target`, `testdata`, `tmp` and `vendor` at any depth; `app/assets/builds`, `app/assets/fonts`, `app/assets/images`, `db`, `public`, `src-tauri/gen`, `src-tauri/permissions/autogenerated` and `test` from the root of each repository; Rails generator templates (`generators/**/templates/`). |
| Excluded files    | `package-lock.json`, `pnpm-lock.yaml`, `npm-shrinkwrap.json`, `*.min.js`, `*.min.css`, symlinks, and the `exclude_files` of the optional configuration file.                                                                                                                                                                                                 |
| Supported formats | Only files with a dedicated formatter, or an extension Prettier formats out of the box, are cleaned. `LICENSE`, `.env`, images and other unknown files are left alone.                                                                                                                                                                                       |

The folders excluded from each repository root (`db`, `public`, `test`…) hold generated or vendored content that repositories commit, such as `db/schema.rb` or generated Tauri schemas, and test fixtures that must stay as written.

## Tuning the run: threads and excluded files

The run is parallelized with threads, `min(number of CPUs, 8)` by default: each formatter runs as a separate process, so threads do not wait on each other. Set `CLEANER_THREADS` to change it:

```bash
CLEANER_THREADS=4 immosquare-cleaner .
```

To exclude more files, list them in `exclude_files` of the optional configuration file `config/initializers/immosquare-cleaner.rb`, with paths relative to the repository root. The file is described in [Ruby, ERB and YAML locales](ruby-erb.md#configuration-file-and-gemfile-setup-for-ruby-projects); `exclude_files` applies to every format, not only Ruby.

```ruby
ImmosquareCleaner.config do |config|
  config.exclude_files = ["src/generated/client.ts", "docs/vendor/legacy.css"]
end
```

From Ruby, `ImmosquareCleaner.clean_directory("path/to/repository")` runs the same clean.
